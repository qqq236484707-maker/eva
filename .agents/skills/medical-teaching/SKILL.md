# 医学教学课件

这是为本项目新编写的工作流，不是第三方文档技能的副本。

## 开始

读取项目 AGENTS.md、已有大纲、交接记录、来源和生成脚本；优先续作而不是重做。沿用用户已确认的授课要求。只有关键缺项会改变结果时才询问。不要把仓库名称当作当前授课题目。

## 证据与内容

1. 清点资料。按需要使用当前环境已有的 PDF/Word/PPT 工具；没有时可用 pypdf 或 pdfplumber 提取 PDF，python-docx 读取 Word，python-pptx 读取幻灯片。扫描件必须说明 OCR 局限，关键数字对照原页。
2. 建立 sources.md：来源编号、题名、机构/作者、年份、URL/DOI、页码或条款、核验日期、适用人群和局限。没有读到全文就标明，不推断不存在的推荐等级。
3. 医学结论检索原始指南或研究；GCP 核对适用地区、发布和生效日期及是否被替代。无联网能力时明确资料截止日期和待核验项，不声称“最新”。
4. 将真实病例去标识化；虚构教学病例必须标为模拟病例。不得捏造患者结果或引用。
5. 写 outline.md，分配章节时间；再写 slide-content.md。每页包含：页码、标题、教学目的、屏幕正文、图表说明、互动问题及答案、引用编号。详细型课件保留关键解释在页面上，内容过多时拆页。
6. AKI/CRRT 聚焦识别、防治、置管和管理；ECMO 区分模式及适用场景；GCP 采用条款与情境讨论。具体剂量、阈值和设备参数必须有来源及适用条件，不在本技能固化数值。

## 文件生成

先检查依赖，参见仓库 tools/requirements-teaching.txt。优先使用宿主已有并获授权的文档工具；若没有，独立编写 python-pptx 生成脚本，使用官方库文档。可用 python-docx 生成讲义、openpyxl 建立证据表。不得自动下载未授权的第三方专有技能。

- 将生成脚本和内容分离，保留可重复生成入口；不要覆盖用户原稿。
- 采用 16:9，确认中文字体可用；优先可编辑文字、表格、形状和数据图表。
- 数据图表标明单位、来源、样本及时间；示意图标明“示意”，不用装饰性图形暗示真实数据。
- 可调用 $theme-factory 选择主题；其原字体不保证中文覆盖，应单独检查。
- 只有用户需要动画时才调用 $slack-gif-creator；将 Slack 尺寸改为适合课堂的输出，医学过程需由核实内容驱动。网页交互不能假称已嵌入 PPT。

## 验证与交付

1. 重新读取输出文件，核对页数、标题、正文和引用编号；检查遗留占位文字与漏页。
2. 用可用 Office 渲染器导出 PDF，逐页检查中文、边界、遮挡、表格和引用。无法渲染时明确“未完成视觉验证”。
3. 检查所有关键结论是否能回到来源，并用学员视角检查术语、病例问题及答案。文件结构正确不代表医学正确。
4. 交付 PPTX、逐页稿、来源清单；按需求交付 PDF/讲义。说明执行了哪些检查及尚存限制。
5. 提交代码或资料前检查隐私与版权；公开仓库不得上传患者资料、内部文件或无再分发许可的论文全文。
